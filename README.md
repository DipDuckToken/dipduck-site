# Dip Duck ($DIPDUCK)

**English** · [Français](#français)

Official website of Dip Duck: **https://dipduck.xyz**

Dip Duck is a meme token on Robinhood Chain (chain ID 4663). No promise of price or returns.
**Not affiliated with Robinhood.**

The website is static (HTML, CSS, JavaScript, no dependencies) and available in 4 languages:
meme generator, collectible cards, a mini-game on the real Bitcoin chart, and a personal
history of the connected wallet's transactions.

- `public/`: the published website.
- `tools/`: scripts that update the data (Bitcoin history, ETH price) and the card images.
- `.github/workflows/pages.yml`: publishing to GitHub Pages, on every change and every day.

The only official contract address is the one shown on the website.
